# Tsumory 開発フェーズ

[mymanifesto.md](mymanifesto.md) のコンセプト 3 点（コンセプト・ユーザー体験・AI のトーン）に照らして、
**「つぶやく → AI が日記にする → 作り直す」のコアループが完結すること**を最優先に切り分ける。

## 切り分けの判断基準

- **MVP に入れるか？** → それが無いとコアループが回らないか
- **フェーズ 2 に回すか？** → コアループは回るが、続ける動機や振り返りの価値を高める機能か

## フェーズ 1（MVP）：コアループの最短実装

**目的**: コンセプト 3 点が成立することを検証する

- ひとことつぶやくだけで、自分の日記が残るか（コンセプト）
- つぶやきを直しながら、納得いくまで作り直せるか（ユーザー体験）
- 生成された日記を「自分の日記」として受け取れるか（AI のトーン）

### 機能

| # | 機能 | 内容 |
|---|---|---|
| 1 | ログイン・ログアウト | Spring Security + BCrypt。初期ユーザーは Flyway マイグレーションで INSERT する |
| 2 | つぶやき投稿 | フォームから 100 文字程度のひとことを投稿する。投稿時刻は自動で付ける |
| 3 | 当日のつぶやき一覧 | 今日のつぶやきを時系列で表示する |
| 4 | つぶやきの編集 | 投稿時刻は保ったまま、本文を直せる |
| 5 | つぶやきの削除 | 自分のつぶやきを削除できる |
| 6 | 日記生成 | Claude API で、当日のつぶやきを 1 本の日記に再構成する |
| 7 | 日記表示 | 当日の日記を 1 本表示する |
| 8 | 日記の再生成 | 同じ日付の日記を上書きする。何度でもできる |

1〜8 がそろうと、「つぶやく（2・3）→ 日記にする（6・7）→ つぶやきを直して（4・5）作り直す（8）」が一周する。

### MVP で意図的に落とすもの

| 落とすもの | 理由 |
|---|---|
| ユーザー登録 UI | 初期ユーザーはマイグレーションで投入すれば、コアループの検証には足りる |
| 過去日記の閲覧／カレンダー | まず「今日 1 本」が成立するかが先 |
| 通知・リマインド | まず通知なしで自然に使われるかを見る |
| 任意日付での日記生成 | 「今日まとめる」だけで概念検証は足りる |

## フェーズ 2：体験を厚くする拡張

コアループは MVP で回る前提で、**続ける動機**と**振り返りの価値**を高める。

| 機能 | ねらい |
|---|---|
| AI によるつぶやきのカテゴリ自動分類 | 積もったつぶやきに意味のまとまりを与え、振り返りやすくする |
| 過去の日記一覧 | 日記が「積もっていく」ことを目に見える形にし、続ける動機にする |
| 検索 | 過去のつぶやきや日記から、あの日の出来事を探し出せるようにする |
| 遡り生成 | 今日以外の日付でも日記を生成・再生成できるようにする |
