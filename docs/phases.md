# Tsumory 開発フェーズ

[mymanifesto.md](mymanifesto.md) のコンセプト 3 点（コンセプト・ユーザー体験・AI のトーン）に照らして、
**「つぶやく → AI が日記にする → 作り直す」のコアループが完結すること**を最優先に切り分ける。

## 切り分けの判断基準

- **MVP に入れるか？** → それが無いとコアループが回らないか
- **フェーズ 2 に回すか？** → コアループは回るが、続ける動機や振り返りの価値を高める機能か

## フェーズ 1（MVP）：コアループの最短実装

**目的**: コンセプト 3 点が成立することを検証する

- ひとことつぶやくだけで、自分の日記が残るか（コンセプト）
- つぶやきを直しながら、納得いくまで作り直せるか（ユーザー体験）
- 生成された日記を「自分の日記」として受け取れるか（AI のトーン）

### 機能

| # | 機能 | 内容 |
|---|---|---|
| 1 | ログイン・ログアウト | Spring Security + BCrypt。初期ユーザーは Flyway マイグレーションで INSERT する |
| 2 | つぶやき投稿 | フォームから 100 文字程度のひとことを投稿する。投稿時刻は自動で付ける |
| 3 | 当日のつぶやき一覧 | 今日のつぶやきを時系列で表示する |
| 4 | つぶやきの編集 | 投稿時刻は保ったまま、本文を直せる |
| 5 | つぶやきの削除 | 自分のつぶやきを削除できる |
| 6 | 日記生成 | Claude API で、当日のつぶやきを 1 本の日記に再構成する |
| 7 | 日記表示 | 当日の日記を 1 本表示する |
| 8 | 日記の再生成 | 同じ日付の日記を上書きする。何度でもできる |

1〜8 がそろうと、「つぶやく（2・3）→ 日記にする（6・7）→ つぶやきを直して（4・5）作り直す（8）」が一周する。

### MVP で意図的に落とすもの

| 落とすもの | 理由 |
|---|---|
| ユーザー登録 UI | 初期ユーザーはマイグレーションで投入すれば、コアループの検証には足りる |
| 過去日記の閲覧／カレンダー | まず「今日 1 本」が成立するかが先 |
| 通知・リマインド | まず通知なしで自然に使われるかを見る |
| 任意日付での日記生成 | 「今日まとめる」だけで概念検証は足りる |

### 画面設計

画面は**ログイン・今日のつぶやき・日記表示の 3 つ**だけにする。
「つぶやく」場所と「日記を読む」場所を分け、それぞれの画面をひとつの役割に絞る。つぶやきの編集は別画面にせず、今日のつぶやき画面の編集モードで行う。2 つの画面は 1 タップで行き来できるようにし、コアループ（つぶやく → 日記にする → 直して作り直す）を往復で回す。

各画面の項目・文言の詳細は [phase1-spec.md](phase1-spec.md) の「4. 画面」を参照。
フェーズ 1・2 の全画面のワイヤーフレーム（スマホサイズ、画面間のリンクをクリックして遷移を確認できる）は [Tsumory 画面設計（デザインキャンバス）](https://claude.ai/artifact/QUXs83eVNV1YbM3vQPTfCq) を参照。共有されていない場合は、作成者以外は開けない。

#### 画面一覧

| 画面 | URL | 役割 | 対応する機能 |
|---|---|---|---|
| ログイン | `/login` | ユーザー名とパスワードでログインする | 1 |
| 今日のつぶやき | `/`（編集モードは `/?edit={id}`） | つぶやく・一覧を見る。編集モードで直す・消す | 2・3・4・5 |
| 日記表示 | `/diary/{date}` | その日の日記を読む・書く・作り直す。MVP では今日の日付だけ | 6・7・8 |

エラー画面（404・500）は画面数に数えない。

#### 画面遷移

```
          ログイン成功
ログイン ─────────────▶ 今日のつぶやき ──「今日の日記へ」──▶ 日記表示
   ▲                    │   ▲      ▲                         │  ├ 日記を書く ─┐
   │                    │   │      └──「つぶやきを直す」─────┘  └ 作り直す ──┴▶ 日記表示に戻る
   │                    │   │
   │                    │   └ つぶやく／保存／削除（同じ画面に戻る）
   │                    └ 「編集」→ 編集モード（同じ画面のまま、その行だけフォームになる）
   └── ログアウト（どの画面からも）
```

#### 今日のつぶやき

```
┌──────────────────────────────────────┐
│ Tsumory                demo  [ログアウト] │
├──────────────────────────────────────┤
│ 2026年10月7日（水）                     │
│ ひとこと                               │
│ ┌──────────────────────────────────┐ │
│ │ いま、なにしてる？                   │ │
│ └──────────────────────────────────┘ │
│                     残り 100 字 [つぶやく] │
│                                      │
│ 今日のつぶやき                          │
│  08:12  寝坊した。目覚まし 3 回止めてた [編集] │
│  12:40  昼のカレーが辛すぎた         [編集] │
│         編集済み                       │
│  18:05  帰り道、金木犀の匂いがした    [編集] │
│                                      │
│ ┌──────────────────────────────────┐ │
│ │      今日の日記へ  →               │ │
│ └──────────────────────────────────┘ │
│ 日記あり（21:30 に作成）                 │
└──────────────────────────────────────┘
```

- 上から「書く（投稿）→ 積もる（つぶやき）→ 日記へ」の順に並べる
- 一覧には「編集」だけを置き、「削除」は編集モードの中に入れる（一覧をすっきりさせ、誤って消さないため）
- 日記の本文はこの画面に出さない。日記の有無と作成時刻だけを添えて、日記表示へ誘導する

#### 今日のつぶやき（編集モード）

```
│ 今日のつぶやき                          │
│  08:12  寝坊した。目覚まし 3 回止めてた [編集] │
│ ┌──────────────────────────────────┐ │
│ │ 12:40 の投稿（投稿時刻は変わりません）  │ │
│ │ ┌──────────────────────────────┐ │ │
│ │ │ 昼のカレーが辛すぎた。でもまた行く │ │ │
│ │ └──────────────────────────────┘ │ │
│ │                      残り 83 字    │ │
│ │ [削除]          [キャンセル] [保存] │ │
│ └──────────────────────────────────┘ │
│  18:05  帰り道、金木犀の匂いがした    [編集] │
```

- 「編集」を押した行だけがその場でフォームに変わる。同時に編集できるのは 1 件
- 保存・削除・キャンセルのあとは通常の表示に戻る
- 保存しても日記は自動で作り直さない

#### 日記表示

```
┌──────────────────────────────────────┐
│ Tsumory                demo  [ログアウト] │
├──────────────────────────────────────┤
│ （メッセージ：日記を書きました など）        │
│                                      │
│ 2026年10月7日（水）の日記                │
│ ┌──────────────────────────────────┐ │
│ │ 目覚ましを 3 回も止めて、今日は寝坊  │ │
│ │ から始まった。昼に食べたカレーは辛す │ │
│ │ ぎた。帰り道、どこからか金木犀の匂い │ │
│ │ がして、もうそんな季節なんだと思った。│ │
│ └──────────────────────────────────┘ │
│ 21:30 に作成                 [作り直す] │
│                                      │
│ しっくりこないときは、つぶやきを直してから   │
│ 作り直せます         [← つぶやきを直す]   │
└──────────────────────────────────────┘
```

- 日記がまだない日は「その日のつぶやき N 件から日記を書きます」と「日記を書く」ボタン。つぶやきが 0 件ならボタンは押せない
- 生成中はボタンを無効にして「日記を書いています…」。失敗したらメッセージを出し、前の日記はそのまま残す
- 日記の本文には編集の操作を付けない（日記を変える方法は再生成だけ）

#### 共通

- Bootstrap 5 で、スマホ幅でも 1 列で読めるレイアウトにする（スマホから思いついたときに投稿する使い方が中心のため）
- ヘッダーにはサービス名・ログイン中のユーザー名・ログアウトだけを置く。MVP ではメニューを持たない

## フェーズ 2：体験を厚くする拡張

コアループは MVP で回る前提で、**続ける動機**と**振り返りの価値**を高める。

| 機能 | ねらい |
|---|---|
| AI によるつぶやきのカテゴリ自動分類 | 積もったつぶやきに意味のまとまりを与え、振り返りやすくする |
| 過去の日記一覧 | 日記が「積もっていく」ことを目に見える形にし、続ける動機にする |
| 検索 | 過去のつぶやきや日記から、あの日の出来事を探し出せるようにする |
| 遡り生成 | 今日以外の日付でも日記を生成・再生成できるようにする |

### 画面設計

フェーズ 1 の 3 画面はそのまま残し、**日記一覧と検索の 2 画面を足す**。日記表示（`/diary/{date}`）は今日以外の日付も開けるようにする。ヘッダーにメニュー（今日・日記一覧・検索）を加える。
ワイヤーフレームは [Tsumory 画面設計（デザインキャンバス）](https://claude.ai/artifact/QUXs83eVNV1YbM3vQPTfCq) の下段を参照。

#### 画面一覧（追加・変更分）

| 画面 | URL | 役割 | 対応する機能 |
|---|---|---|---|
| 今日のつぶやき（変更） | `/` | 各つぶやきにカテゴリを表示する | カテゴリ自動分類 |
| 日記表示（変更） | `/diary/{date}` | 今日以外の日付も開ける。過去の日にも日記を書く・作り直すができる。その日のつぶやきも読める | 遡り生成 |
| 日記一覧（追加） | `/diaries` | 過去の日記を新しい順に並べる。月ごとのカレンダー表示も切り替えられる | 過去の日記一覧 |
| 検索（追加） | `/search?q=...` | キーワードとカテゴリで、つぶやきと日記を探す。結果から日記表示へ移る | 検索 |

#### 画面遷移（追加分）

```
今日のつぶやき ─メニュー─▶ 日記一覧 ─日付を選ぶ─▶ 日記表示（/diary/{その日}）
      │                                              ▲
      └──────メニュー─▶ 検索 ──結果を選ぶ────────────┘
```

- 日記表示はフェーズ 1 と同じ画面を使い、「今日」を「指定した日」に広げる。コアループの操作感を過去の日でも変えない
- カテゴリは AI が付けるラベルとして表示するだけにし、ユーザーが手で付け替える操作はフェーズ 2 でも持たない（「書かなくていい」体験を崩さないため）
