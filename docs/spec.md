# 仕様書群の索引

Tsumory の仕様は責務ごとに複数のファイルに分かれている。このファイルは各仕様書への入口（索引）として機能する。

- [mymanifesto.md](mymanifesto.md)：サービスコンセプト・ユーザー体験・AI のトーン
- [phases.md](phases.md)：フェーズ分割（MVP / 拡張）と、各フェーズで何を作って何を作らないか
- [phase1-spec.md](phase1-spec.md)：フェーズ 1（コア MVP）の要件・画面設計・エンドポイント・データモデル・ER 図
- [phase2-spec.md](phase2-spec.md)：フェーズ 2（カテゴリの自動分類と手動修正・日記一覧・検索・遡り生成）の、フェーズ 1 からの追加・変更分。phase1-spec.md と食い違う箇所はこちらが正

各ファイルが責務ごとに独立しているため、追記・修正は対象ファイルに直接行う。このファイルは「どこを見ればよいか」を示す入口の役割に徹し、内容を集約しない。
