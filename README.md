# Tsumory

ユーザーが投稿した「つぶやき」を、AI（Claude）が 1 日の日記にまとめる Web サービスです。

この資料は、開発に関わっていない方（上司・レビュアーなど）が、**進捗を確かめる**・**本番や手元の PC でアプリを動かして見る**ための案内です。

> **現在の状況（2026-11-27）**
> 写真・音声機能の追加は、2026年11月27日にリリースしました。マイルストーン（M0〜M7）はすべて完了し、テスト 80 件は PASS 79 件・対象外 1 件です。
> 本番環境（Railway の無料プラン）は、公開 URL で見られます（「1. 何が見られるか」）。

## 1. 何が見られるか

| 見たいもの | 場所 | 必要なもの |
|---|---|---|
| 進捗（WBS） | `WBS_tsumory.xlsx`（Excel） | Excel だけ。GitHub からダウンロードできる |
| 仕様 | `docs/spec.md`（各仕様書への入口） | ブラウザだけ。GitHub 上でそのまま読める |
| アプリの動き（本番） | https://tsumory-production-20ff.up.railway.app | ブラウザ（PC の Chrome か Edge）と、開発者から別に受け取る資格情報 |
| アプリの動き（手元） | 自分の PC で起動する | Java・Docker など（「3.」） |

本番で見るとき

- 開くと、まずブラウザの認証の画面（ユーザー名とパスワード）が出ます。そのあとに、アプリのログイン画面が出ます。どちらの資格情報も、このリポジトリには書いていないので、開発者から別に受け取ってください
- 本番のデータは実際のものです。試しに投稿したつぶやきは、見終わったら削除してください
- 無料プランのため、しばらく使われていないとアプリが止まり、次に開いたときに起き上がります。最初の 1 回は表示まで時間がかかることがあります
- 音声入力は、PC 版の Chrome・Edge で使えます。ほかのブラウザでは、キーボードで入力してください

## 2. 進捗（WBS）を見る

写真・音声機能の追加（2026年11月27日にリリース済み）の計画と進捗です。

### Excel で見る（おすすめ）

1. GitHub のリポジトリのトップで `WBS_tsumory.xlsx` をクリックする
2. 右上の「ダウンロード」のボタン（下向きの矢印）を押す
3. ダウンロードしたファイルを Excel で開く

| シート | 内容 |
|---|---|
| 00_概要 | 対象・完成日・品質の基準と、進捗の自動集計（マイルストーンの完了数、テストの PASS 数など） |
| 01_マイルストーン | M0〜M7 の予定日・達成基準・状況 |
| 02_機能要件 | 写真・音声・共通の要件と受入条件 |
| 03_方式・画面設計 | 処理の流れ・データ・API の設計 |
| 04_テスト計画 | テストの方針・環境・開始と終了の条件 |
| 05_テストケース | 80 件のテストケースと、その実施状況・判定 |
| 06_課題・リスク | 決めるべき設計判断とリスク |
| 07_不具合管理 | 見つかった不具合と再テストの結果 |

### 最新の内容について

- WBS の作業用の原本は `WBS_tsumory.md`（Markdown）です。日々の更新はこちらに入り、Excel には区切りのよいところでまとめて反映します
- そのため、**Excel は前回反映した時点の内容**です。いちばん新しい内容を見たいときは、GitHub 上で `WBS_tsumory.md` を開いてください（ブラウザでそのまま読めます）
- 運用の決まりは `WBS_tsumory.README.md` にあります

## 3. アプリを手元で動かす

自分の PC でアプリを起動し、ブラウザで操作して見る手順です。Windows を前提に書いています。初回は 30 分ほどかかります。

### 3-1. 用意するもの

| もの | 用途 | 入れ方の例（Windows） |
|---|---|---|
| Git | ソースコードを取ってくる | `winget install --id Git.Git` |
| Java 21（JDK） | アプリを動かす | `winget install --id EclipseAdoptium.Temurin.21.JDK` |
| Docker Desktop | データベース（PostgreSQL）を動かす | `winget install --id Docker.DockerDesktop` |
| Claude API のキー | 日記の生成とカテゴリの分類 | https://console.anthropic.com で発行する |

- コマンドは PowerShell で実行します。入れたあとは、PowerShell を開き直してください
- Docker Desktop は、インストールしたあとに一度起動し、画面の案内に従って初期設定を済ませてください
- **Claude API は使った分だけ料金がかかります**（日記の生成と、つぶやきの投稿・編集のたびに呼ばれます）。キーはほかの人と共有せず、自分のものを使ってください

### 3-2. ソースコードを取ってくる

```
git clone https://github.com/fuji-t88/tsumory.git
cd tsumory
```

### 3-3. API キーを設定する

1. `tsumory` フォルダの `.env.example` をコピーし、名前を `.env` にする
2. `.env` をメモ帳で開き、`ANTHROPIC_API_KEY=` の後ろにキーを書く

```
ANTHROPIC_API_KEY=sk-ant-xxxxxxxx
```

- 値は `"` で囲まない
- `.env` は Git に入らないので、キーが外に出ることはありません

### 3-4. 起動する

1. Docker Desktop を起動しておく
2. `tsumory` フォルダで次を実行する

```
./gradlew bootRun
```

- データベースも自動で立ち上がります
- 初回は部品のダウンロードで数分かかります。`Started TsumoryApplication` と表示されたら起動完了です
- この画面（PowerShell）は閉じずにそのままにしておきます

### 3-5. ログインできるようにする（初回だけ）

クローンした直後は、初期ユーザー `demo` のパスワードが分からないため、ログインできません。自分でパスワードを決めて設定します。

1. パスワードを決めて、その「ハッシュ」（パスワードを読めない形に変換したもの）を作る。新しい PowerShell を開き、`あなたのパスワード` の部分を書き換えて実行する

   ```
   docker run --rm httpd:2.4-alpine htpasswd -nbBC 10 demo あなたのパスワード
   ```

   `demo:$2y$10$....` のような 1 行が表示されます。`demo:` より**後ろ**（`$2y$10$` から行の最後まで）をコピーします

2. ブラウザで http://localhost:8081 （データベースの管理画面 Adminer）を開き、次のとおり入力してログインする

   | 項目 | 入力する値 |
   |---|---|
   | データベース種類 | PostgreSQL |
   | サーバ | `db` |
   | ユーザ名 | `tsumory` |
   | パスワード | `secret` |
   | データベース | `tsumory` |

3. 左の「SQL コマンド」を押し、次の SQL を貼り付ける。`ここにコピーしたハッシュ` の部分を、1. でコピーした値に置き換えて「実行」を押す

   ```sql
   UPDATE users SET password_hash = 'ここにコピーしたハッシュ' WHERE username = 'demo';
   ```

   変更した行の数が「1」と出れば完了です（「0」なら、アプリを一度起動してからやり直す）

### 3-6. 見本のデータを入れる（任意）

空のままでは、日記の一覧や検索の画面に何も出ません。過去 7 日分のつぶやきと日記の見本を入れられます。

1. Adminer の「SQL コマンド」を開く
2. `tsumory` フォルダの `db/dev-seed.sql` をメモ帳で開き、中身をすべてコピーして貼り付け、「実行」を押す

- 流すたびに、`demo` の過去 7 日分のデータを消してから入れ直します（自分で投稿した分も消えます）

### 3-7. 使ってみる

1. ブラウザで http://localhost:8080 を開く
2. ユーザー名 `demo`、3-5 で決めたパスワードでログインする
3. つぶやきを投稿したり、日記を生成したりしてみる

### 3-8. 止める

- `./gradlew bootRun` を実行している PowerShell で `Ctrl + C` を押す。データベースも一緒に止まります
- データは消えずに残るので、次は 3-4 から始められます

## 4. うまくいかないとき

| 症状 | 原因と対処 |
|---|---|
| 起動時に `ANTHROPIC_API_KEY` に関するエラーが出る | `.env` がない、またはキーが書かれていない。3-3 をやり直す |
| 起動時に Docker に関するエラーが出る | Docker Desktop が起動していない。起動してからやり直す |
| `Port 8080 was already in use` と出る | ほかのアプリが 8080 番を使っている。そのアプリを止める |
| ログインできない | 3-5 のパスワードの設定がまだ。または `UPDATE` で `0 行` だった（アプリを一度起動してから行う） |
| IntelliJ IDEA で開くと「Dependency verification failed」になる | IDE の同期だけで起きることがある。コマンドの `./gradlew bootRun` は動く |
| 日記の生成でエラーが出る | API キーが正しくない、または Claude API の残高・利用上限。https://console.anthropic.com で確認する |
